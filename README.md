# SHOP.CO - Modern E-Commerce Storefront

A fully responsive, premium fashion e-commerce storefront built with **React**, **Vite**, and **SASS**. This project features interactive dynamic filters, comprehensive search suggestions, an interactive cart system, and an integrated login validation portal.

## ✨ Key Features

* **Custom Authentication Gate:** Secures the homepage, prompting users with validated login and signup layouts first.
* **Dynamic Search & Instant Suggestions:** Standard search overlay that dynamically filters catalog products in real-time.
* **Interactive Navigation Filters:**
  * **On Sale:** Instantly filters products displaying active discounts with clean clear-filter toggles.
  * **New Arrivals:** Displays the latest trending items from the data list.
  * **Brands:** Smoothly scrolls down to the brand logos banner on the Homepage from anywhere on the site.
* **Responsive Vector Sparkles:** Renders premium custom SVG graphic stars that scale dynamically on mobile screens.
* **Fully Featured Cart System:** Supports real-time subtotal calculations, product quantity scaling, item removal, and live icon badge count.
* **Aesthetic CSS/SCSS Styling:** Modularized SCSS variables and custom responsive grids.

## 📦 Local Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/sfaiz801/Shop.co.git
   ```
2. Navigate to the project directory:
   ```bash
   cd shop-co
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
